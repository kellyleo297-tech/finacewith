## 简历项目文案（最终版）

---

作为 AI 产品独立项目，面向 18-28 岁学生及年轻白领，打造个人财务管理 Agent。针对用户收入相对固定、消费高频碎片化、预算感知弱等问题，设计从收支记录、预算管理、消费分析到储蓄规划的完整产品闭环。产品已正式上线：Web 端（finacewith.vercel.app）、PWA 一键安装、macOS 原生桌面端（Tauri 构建，6.6MB，GitHub Releases 可下载），前端 7 页面 + 后端 12 API 接口 + Supabase 7 张数据表，代码开源并配有完整 PRD 与技术文档。

**用户洞察：** 通过用户访谈与竞品分析，识别年轻用户"记账后看不懂、月底才发现超支、想攒钱但缺少个性化指导"三类核心问题，将产品目标定义为帮助用户实时理解消费、控制预算，并获得可执行的财务建议。

**AI 能力：** 设计 Supervisor Agent + 6 个专业 Agent 的多 Agent 协作架构，覆盖智能记账、消费分析、预算规划、储蓄目标、理财教育及消费决策；采用"规则优先、LLM 兜底"的混合路由机制，各 Agent 配置独立 System Prompt、上下文及温度参数，支持单独评测与持续优化。相比单体 Agent 方案，多 Agent 架构使每个模块可独立评测、独立调参、独立切换底层模型，且风控 Agent 与其他 Agent 零代码耦合。

**产品设计：** 采用"代码算账，Agent 解释"原则——金额、预算及统计由代码完成，AI 负责意图理解与结果解释，降低财务数据幻觉风险；AI 识别记账信息后生成确认卡片，经用户确认再写入账本（有意为之的"摩擦设计"）；首页聚焦"今天还能花多少"，将月底事后复盘转化为消费前的实时决策支持。

**风控设计：** 针对投资、收益、借贷等高风险内容设计二次审核机制，建立不推荐具体股票、不承诺收益、不诱导借贷投资等 7 类合规红线；采用"红线直接拦截、黄线增加风险提示"的分级策略，并将 AI 输出统一设计为"分析依据 + 建议方案 + 风险提示"三段式结构。

**上线与迭代：** 独立完成从 PRD 到全栈交付，前端 React + Vercel Serverless 后端 + Supabase 数据库 + DeepSeek AI 引擎。产品已在线运行，根据用户反馈持续优化，包括统计页日期动态同步、AI 记账确认卡片交互优化、PWA 离线支持及桌面端适配等迭代。

**冷启动与用户反馈：** 通过小红书内容发布、朋友圈定向邀请及用户访谈等方式进行种子用户获取，收集定性反馈驱动产品迭代。MVP 阶段以用户行为观察和深度访谈为核心手段，验证核心需求假设并持续优化产品体验。

**AI Agent 评测体系：** 设计三维评测框架（意图分类 / 安全合规 / 端到端质量），构建 42 条中文真实用户场景测试集覆盖 7 类意图。通过三轮数据驱动迭代将 Supervisor 规则层命中率从 13% 提升至 87%，模型调用量较纯 LLM 方案下降 74%。设计 11 条红线 / 黄线 / 合规分级风控场景。端到端链路 4 场景全通过。评测脚本使用 TypeScript 编写，支持一键复跑。

## 面试追问应对表

| 追问 | 回答要点 |
|------|---------|
| "为什么 7 个 Agent 不是一个 GPT 全搞定？" | 单体 Agent 评测困难、优化困难、一个模块出问题全挂。7 Agent 可独立评测、独立调 prompt、独立调温度参数。风控 Agent 零耦合，确保高风险场景不被主流程绕过。 |
| "规则层命中率 87%，剩下的 13% 怎么办？" | 走 LLM 兜底。当前 87% 已经省了 74% 的 API 调用。13% 的漏判案例主要是模糊表达和长尾场景，不适合用规则硬 cover——那些正是应该交给 LLM 的地方。 |
| "13%→87%，改动了几行代码？" | 核心改动是匹配逻辑：`every`→`some`（bug 修复），关键词长度阈值 3→2，匹配策略从单组内部匹配改为跨组计数+最优规则选择。代码改动不大，但效果提升巨大——这就是评测的价值。 |
| "评测用例 42 条是不是太少了？" | MVP 阶段手工标注。框架已设计好，加用例只需在数组里加一行配置。下一步接入线上日志自动扩充到 200+，并引入 LLM-as-Judge 自动评分。 |
| "风控 100% 拦截是真的 100% 吗？" | 11 条场景的设计目标是 100%，实际执行需要调用 LLM 验证。评测框架已就绪，API 跑一遍即出结果。重点是：红线规则定义清晰、场景覆盖完整、指标明确。 |
| "你自己写代码的吗？理解多深？" | 独立完成全栈。PRD → React 前端 → Express 后端 → Supabase 建表 → DeepSeek Agent 集成 → Vercel 部署 → Tauri 桌面端。代码在 github.com/kellyleo297-tech/finacewith。 |
